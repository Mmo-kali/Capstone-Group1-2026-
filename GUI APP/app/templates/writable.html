About DACL Abuse

A Discretionary Access Control List (DACL) defines who can perform actions on an Active Directory object. This check looks for user objects where the selected profile has GenericAll rights, which means full control over that object. With that level of control, an operator may be able to reset the target account password and authenticate as that user.

Recommendation

Review delegated permissions on high-value users, groups, and organizational units. Remove unnecessary GenericAll, GenericWrite, WriteDacl, WriteOwner, and AllExtendedRights permissions, especially for low-privileged users. Monitor directory ACL changes and use least-privilege delegation for administrative tasks.
