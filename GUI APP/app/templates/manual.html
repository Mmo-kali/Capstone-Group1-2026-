Recommended Workflow

Create or Select a Profile

Save domain credentials, DC IP, domain name, and DC FQDN before running any module.

Run Checks First

Use check actions to confirm targets and permissions before running exploit actions.

Review Results

Exploit output appears in the right or lower results panel, depending on the module layout.

Open Password Vault

When hashes are saved, Password Vault is highlighted as the next step in the sidebar.

3

Attack Modules

Kerberoasting

Checks for service accounts with SPNs and requests TGS hashes for offline cracking.

Open Kerberoasting

AS-REP Roasting

Finds accounts without Kerberos preauthentication and requests AS-REP hashes.

Open AS-REP Roasting

DCSync

Checks replication rights and dumps NTLM material when the account has DCSync privileges.

Open DCSync

Zerologon

Checks or exploits CVE-2020-1472, then supports machine account password restoration.

Open Zerologon

DACL

Lists GenericAll targets and supports password changes where delegated rights allow it.

Open DACL
4

Password Vault

Kerberoast, AS-REP, and DCSync exploit results are stored in the vault when hashes are collected. The sidebar highlights Password Vault with a next-step badge after successful capture.

Open Vault
5

Recovery Notes

Zerologon Restore

After a successful Zerologon exploit, restore the domain controller machine account password immediately using the Restore Password panel. Confirm the restore result before leaving the module.

Operational Safety

Use this tool only in authorized lab or assessment environments. Validate target details before exploit actions, and keep saved credentials and hashes protected.
